# Roadmap

Current capabilities include explicit source inventories, safe output-path
handling, typed answer validation, generated service tests, native Venus OS
installation scaffolding and versioned source candidate qualification.

Near-term priorities are broader integration coverage across all device types,
full-project statement coverage, generated-code typing, replacing deprecated
Paho callbacks, documenting dependency upgrades, and testing device-specific
acceptance separately from generator checks. Improve command authorization and
physical operating limits in actual generated applications rather than claiming
that generic scaffolding provides them.

Governance priorities are a real backup maintainer and tested access recovery.
Longer-term release priorities include independently verifiable signed source
releases and reproducible-build verification across clean environments.

These are priorities, not committed delivery dates. Proposals and compatibility
changes are discussed in GitHub issues and reviewed pull requests. Completed
changes and migration instructions are recorded in [the changelog](../CHANGELOG.md).
